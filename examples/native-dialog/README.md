# Synthetic research example: native dialog or custom ARIA dialog

This example applies the kit to a fictional product request. No real repository, application, user data, model API or deployment was involved.

Files:

- `RESEARCH.md` — decision, evidence, alternatives and recommendation.
- `SOURCES.csv` — opened primary sources and the claims each one supports.
- `IMPLEMENTATION-BRIEF.md` — a reviewable proposal with acceptance checks and recovery.
- `dialog-prototype.html` — isolated browser probe for native modal behavior; not production code.
- `PROBE-RESULTS.md` — actual run environment and observations, if available.
